# gertix-clone

仿照 [GertiX](https://gertix.studio/)（德国展览营销机构官网）开发的前端静态项目，仅用于前端学习与技术研究。

## 本地预览

```bash
python -m http.server 8080
```

浏览器打开 <http://127.0.0.1:8080/>

## 内容

- 完整页面树：首页、portfolio、studio、exhibitions、business-areas（含 leadgenerierung、markenkommunikation 等业务页）、博客分类页
- WordPress 主题资源：wp-content / wp-includes、媒体库图片、字体
- 德语站页面：agb、datenschutz、impressum、contact
